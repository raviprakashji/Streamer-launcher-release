# Streamer Launcher — Obsidian Branding Assets

TV-calibrated **Lightened SL on Obsidian** brand asset suite generated from the metallic silver `"SL"` + prism Play + broadcast wave mark.

## Palette & TV Contrast Calibration
- **Outer / Ambient Canvas**: `#0B0F17` (deep obsidian)
- **Inner Card Surface**: `#121927` → `#1B263B` radial fill with `#304262` rim and soft top specular gradient to preserve separation under TV HDMI limited-range black compression
- **SL Monogram**: Cool metallic silver `#F4F8FF` → `#C2CFE0` vertical gradient
- **Ambient Glow Accents**: Electric Violet `#8B5CF6` & Neon Cyan `#06D6F8`
